# ESP32-C3 SuperMini — Wireless Tests

Documentation and hardware tests for the ESP32-C3 SuperMini's wireless features.

## Tests

| Test | Description | Status |
|---|---|---|
| [Wi-Fi Scan Test](wifi-test/README.md) | Scan for nearby 2.4 GHz Wi-Fi networks | Passed |
| [Bluetooth LE Test](bluetooth-test/README.md) | Advertise over BLE and detect the board using a phone | Passed |

## Hardware

- Board: ESP32-C3 SuperMini
- Development environment: Arduino IDE
- Serial Monitor: 115200 baud

## Notes

Both tests have been reported as successful on the physical board.
